# Hemora Repository

Coursework for the DBMS course, organised into three folders.

| Folder | Contents |
| --- | --- |
| [`Capstone/`](Capstone/README.md) | Hemora — blood bank, donor matching and inventory management system (React, Express, PostgreSQL). Live at https://hemora-brown.vercel.app |
| `Lab/` | Lab exercises |
| `Assignments/` | Assignment submissions |

Start with [`Capstone/README.md`](Capstone/README.md) for the project overview, setup steps and documentation index.

CI configuration lives in [`.github/workflows/ci.yml`](.github/workflows/ci.yml) and builds `Capstone/backend` and `Capstone/frontend`.
